# Grok's Playground

**Your personal hub for experiments, finance tracking, wedding planning tools, game dev, and AI playgrounds.**

Built with Next.js + Tailwind. Deployed on Vercel.

## Features
- Modern dashboard
- Finance & Crypto overview (mock your M1/CoinTracker data)
- Wedding Planner Hub (checklists, budget tracker)
- RPG Game Tools (character builder inspired by your Warded Man / Demon Cycle projects)
- AI Prompt Playground
- Quick links to your other repos & LinkedIn

## Quick Start
1. `npm install`
2. `npm run dev`
